## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-19 | Elevation of Privilege | Reaching /admin content without admin role | mitigate | Layout re-calls verifyAdminSession() (layer 2 beyond proxy.ts); every mutation is a Plan 03 action that re-verifies again |
| T-05-20 | Input Validation | Client-only alt-text `required` bypassed | mitigate | UI hint is cosmetic; server-side Zod enforcement lives in Plan 03 (T-05-10) — UI does not weaken it |
| T-05-21 | Tampering | Price entered in naira mis-stored as raw kobo | mitigate | Explicit naira↔kobo conversion at the input boundary; server re-validates int().positive() |
</threat_model>
