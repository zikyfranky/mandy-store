<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → admin Server Action | Direct invocation attempting to mutate products without admin role |
| admin action → Vercel Blob | Upload must never be reachable anonymously |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-08 | Elevation of Privilege | Server Action called directly to mutate a product | mitigate | `await verifyAdminSession()` as literal first statement in every action (D-02) |
| T-05-09 | Elevation of Privilege | Anonymous Vercel Blob upload | mitigate | `put()` only reached after verifyAdminSession passes inside the action; no public upload Route Handler created |
| T-05-10 | Input Validation | Empty/whitespace alt text bypassing UI `required` | mitigate | Zod `z.string().trim().min(1)` server-side (Pitfall 6, SC1) |
| T-05-11 | Information Disclosure | Action returns raw Drizzle record with internal fields | mitigate | Minimal DTOs `{success,id}` only (Pitfall 10) |
| T-05-12 | Tampering | Negative/zero price or negative stock persisted | mitigate | Zod int().positive() price, int().min(0) stock |
| T-05-13 | Denial of Service | Oversized image upload exhausting the Function body limit | mitigate | Reject > 4.5MB server-side (Pitfall 5) |
</threat_model>
