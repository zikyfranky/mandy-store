    1. `src/app/(auth)/reset-password/page.tsx` — Server Component mirroring `verify-email/page.tsx`. `interface ResetPasswordPageProps { searchParams: Promise<{ token?: string; email?: string }> }`. Suspense-wrapped async `ResetPasswordContent`: `const { token, email } = await searchParams`.     2. `src/app/(auth)/reset-password/ResetPasswordForm.tsx` — `"use client"`. Props `{ token: string; email: string }`. State: `password`, `error`, `done`, `useTransition`. On submit: `startTransition(async () => { const r = await resetPassword({ email, token, password }); if ("error" in r) setError(r.error); else setDone(true) })`. Disable the submit button while `isPending` (mirror ProductRowActions disabled pattern). Show `error` in a `role="alert"` region. When `done`, replace the form with a success panel: heading "Password updated" + copy "You can now sign in with your new password." + a `<Link href="/account/login">Sign in</Link>`. Use the verify-email page's heading/text/button tailwind classes for visual consistency.
