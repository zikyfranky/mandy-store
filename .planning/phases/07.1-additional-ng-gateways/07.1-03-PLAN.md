```typescript
function parseJsonp(raw: string): unknown {
  const stripped = raw.replace(/^\s*[A-Za-z_$][\w$]*\s*\(/, "").replace(/\)\s*;?\s*$/, "")

}
```

`initPayment(params)` (D-17 — RRR generated BEFORE returning the redirect URL, hidden from callers):
1. `const amountNaira = params.amountKobo / 100` and guard `if (amountNaira > 1_000_000) throw new Error("Remita amount > ₦1M — check unit conversion")` (Pitfall 1, copy flutterwave.ts guard idea).
2. Compute `apiHash = crypto.createHash("sha512").update(merchantId + serviceTypeId + params.reference + String(amountNaira) + apiKey).digest("hex")` (RESEARCH Pattern 5 — orderId is our `params.reference`; **concat order load-bearing**, matches plan-01 fixture).
3. `POST {base}/remita/exapp/api/v1/send/api/echannelsvc/merchant/api/paymentinit` with header `Authorization: remitaConsumerKey=${merchantId},remitaConsumerToken=${apiHash}` + `Content-Type: application/json`; body `{ serviceTypeId, amount: String(amountNaira), orderId: params.reference, payerName: params.customerName, payerEmail: params.email, payerPhone: params.phone ?? "", description: "Order " + params.reference }`. Throw on non-ok (mirror paystack.ts:49-52).
4. Parse the response via `parseJsonp`; expect `statuscode "025"` success (A2) and read `RRR`. Throw if no RRR.
5. Build the onepage GET redirect URL: `${base}/remita/onepage/payment/init.reg?rrr=${RRR}&channel=CARD,USSD,ENAIRA,TRANSFER`.
6. Return `{ mode: "redirect", url } as InitResult`. **The caller (plan-04 action) reads the RRR separately to store as gatewayReference** — expose the RRR by also returning it: return `{ mode: "redirect", url, rrr: RRR }` (the extra field is allowed on the redirect variant via structural typing; document that the action reads `rrr` to persist it — D-17 keeps the generation hidden, but the RRR value itself must reach the action to be stored as `gatewayReference`, per PATTERNS §remita.ts / Runtime State Inventory).

`verifyTransaction(rrr: string)` (D-15 requery):
1. `statusHash = crypto.createHash("sha512").update(rrr + apiKey + merchantId).digest("hex")` (RESEARCH Pattern 5 — **different order** from apiHash).
2. `GET {base}/remita/exapp/api/v1/send/api/echannelsvc/${merchantId}/${rrr}/${statusHash}/status.reg`. Throw on non-ok.

4. Return `VerifyResult { status, amountKobo, currency: "NGN", reference: rrr }`.

`refund(rrr, amountKobo?)`: attempt the Remita refund API if available (A5 uncertain); if unavailable, `console.error` + resolve (degrade to log + manual, acceptable per A5). Document in a comment.
